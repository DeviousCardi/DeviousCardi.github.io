# deviouscardi.github.io

Personal site of Aarav Sunil Jadav: https://deviouscardi.github.io

React + Vite, deployed to GitHub Pages by GitHub Actions. No third-party requests: fonts and scripts are self-hosted, a strict Content Security Policy ships with every page, and `npm run check:publish` gates each deploy.

```sh
npm ci
npm run dev      # local development
npm run build    # production build in dist/
```
